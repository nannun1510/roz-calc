# ROZ item icons
Icons come from the ROZ client: data.grf > data\texture\유저인터페이스\item\<identifiedResourceName>.bmp
(resource names from System/itemInfo_data.lub), converted to PNG with the magenta background made transparent,
saved as src/assets/demo/images/items/<itemId>.png. Script: D:\Gravity\roz-calc-data\tools (icons.py on the extraction machine).
