# ROZ Global Damage Calculator (unofficial)

Fan-made damage calculator for **Ragnarok Zero: Global**.

**Open it:** https://nannun1510.github.io/roz-calc/

- Items, skills, skill ratios and cast/delay timings are extracted from the ROZ Global client.
- Monster stats come from rAthena (kRO renewal) and are not yet verified for ROZ.
- Fork of [latam-ro-calc](https://github.com/adsonpleal/latam-ro-calc) (MIT), itself based on [tong-calc-ro](https://github.com/turugrura/tong-calc-ro).
