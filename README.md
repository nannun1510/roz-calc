# ROZ Global Damage Calculator (unofficial)

Fan-made damage calculator for **Ragnarok Zero: Global**, built on [Tong calc](https://github.com/turugrura/tong-calc-ro) (attackjom's version).

**Open it:** https://nannun1510.github.io/roz-calc/

- Classes: the 6 first jobs and 13 second jobs currently in ROZ Global.
- Items, skill ratios and cast/delay/cooldown timings are extracted from the patched ROZ Global client.
- Monster stats come from rAthena (kRO renewal) and are not yet verified for ROZ.
